Mirror-Network-Test

Тестовое задание. Реализация паттерна Pub/Sub поверх Mirror с использованием VContainer.

Unity: 2022.3.62f3

Инструкция по проверке: Откройте сцену SampleScene, нажмите Play. Весь процесс (Host -> Subscribe & Test) управляется кнопками UI на экране, результаты выводятся в консоль.
